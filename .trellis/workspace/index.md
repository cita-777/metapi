# 工作区索引

> 记录项目中所有开发者的 AI 开发会话。

---

## 概览

此目录保存不同开发者在本项目中的 Trellis 会话记录，便于跨会话恢复上下文。

### 文件结构

```text
workspace/
|-- index.md              # 本文件：总索引
+-- {developer}/          # 每位开发者的目录
    |-- index.md          # 个人索引和会话历史
    +-- journal-N.md      # 会话日志（按序编号）
```

## 开始使用

### 新开发者

运行初始化脚本：

```bash
python3 ./.trellis/scripts/init_developer.py <your-name>
```

该命令会：

1. 创建身份文件（已加入 gitignore）；
2. 创建个人 workspace 目录；
3. 创建个人索引；
4. 创建初始 journal 文件。

### 返回项目的开发者

1. 获取开发者名称：
   ```bash
   python3 ./.trellis/scripts/get_developer.py
   ```
2. 阅读个人索引：
   ```bash
   cat .trellis/workspace/$(python3 ./.trellis/scripts/get_developer.py)/index.md
   ```

## 约定

### 会话日志文件规则（Journal）

- 每个 journal 文件最多 2000 行；
- 达到上限后创建 `journal-{N+1}.md`；
- 创建新文件时同步更新对应个人 `index.md`。

### 会话记录格式

每次会话应包含：

- 摘要：一行说明本次工作；
- 分支：工作所在的 branch；
- 主要变更：修改了什么；
- Git 提交：提交哈希和说明；
- 后续步骤：下一步做什么。

### 会话模板

```markdown
## 会话 {N}：{标题}

**日期**：YYYY-MM-DD
**任务**：{task-name}
**分支**：`{branch-name}`

### 摘要

{一行摘要}

### 主要变更

- {变更 1}
- {变更 2}

### Git 提交

| 哈希 | 提交说明 |
| --- | --- |
| `abc1234` | {提交说明} |

### 测试

- [OK] {测试结果}

### 状态

[OK] **已完成** / # **进行中** / [P] **阻塞**

### 后续步骤

- {后续步骤 1}
- {后续步骤 2}
```

**语言**：Trellis 管理的开发文档默认使用简体中文；命令、路径、代码符号、配置字段、协议名和第三方名称保持规范原文。已有英文历史记录按兼容读取处理，不要求批量回译。
